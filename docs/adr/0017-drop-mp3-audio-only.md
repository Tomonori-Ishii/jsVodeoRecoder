# ADR-0017: 音声だけの録音（MP3）を廃止し、音声は映像の一部にする

- **Status**: Accepted
- **Date**: 2026-11-21

## Context

以前の版は、マイクの音声を MP3 に録音して保存していた（旧 ADR-0003 は、commit `37a128b` の `docs/adr/0003-lamejs-mp3-encoding.md` を参照）。
画面録画を追加するにあたり、MP3 を残すかどうかを決める必要があった。利用者から、MP3 は不要で、音声はモノラルの AAC にするという決定があった。

## Decision

- 録画の出力は mp4 だけにする。MP3 は出力しない。
- 映像の音声は、マイク入力とスピーカーのライン入力を混ぜた、モノラル 1 つのトラック（Opus、48kHz、128kbps。ADR-0026 で AAC から変更）とする（F-022）。
- 要件 F-004（MP3 の保存）、F-005（MP3 のエンコード）、F-006（MP3 のファイル名）は、F-031、F-024、F-032 に置き換える。
- F-001〜F-003（開始、一時停止、再開）と F-007〜F-011（経過時間、音量、マイク選択）は、録画にも使う。

## Consequences

- 実装では、MP3 の録音（`lamejs` を使う `src/recorder.js` の一部）を削除する。削除の時期は実装の計画で決める。
- lamejs の依存は、画面録画の実装が終わったあとに外せる。
- 音量バーと dB 表示（F-008）は、録画中の音声レベルを表示する。
- 既存の音声だけの録音を残す要望が出た場合は、この ADR を見直す。

## 実装での確認（2026-11-21）

- MP3 の録音（lamejs）は削除した。
- この Linux 環境では AAC の符号化ができなかったため、音声の符号化を Opus に変えた（ADR-0026）。
